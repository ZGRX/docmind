# 项目面试问题与参考答案

1. **什么是 RAG？** 检索增强生成：先从外部知识中取相关片段，再把片段作为上下文交给生成模型。
2. **为什么不用直接把整个 PDF 发给 LLM？** 长文档可能超过上下文限制，成本高，也会混入大量无关内容。
3. **什么是 Embedding？** 把文本映射成向量，便于按语义相似度搜索。
4. **为什么需要向量数据库？** 它持久保存向量及元数据，并提供高效近邻查询。
5. **top-k 是什么？** 一次检索返回最相近的 k 个 chunk。
6. **chunk size 怎么选？** 在语义完整性、召回率和上下文成本之间平衡，结合真实问题评测。
7. **chunk overlap 有什么用？** 缓解信息刚好跨越两个 chunk 边界时的丢失。
8. **ChromaDB 怎么做相似度查询？** 对问题向量和已存向量做近邻搜索；本项目 collection 使用余弦距离。
9. **为什么上传和提问使用同一个 Embedding 模型？** 保证文档与问题向量处在同一语义空间且维度兼容。
10. **FastAPI 为什么适合本项目？** 支持参数校验、自动 API 文档、依赖注入和流式响应，代码简洁。
11. **StreamingResponse 如何实现？** 把生成器产生的 SSE 字符串持续写入 HTTP 响应。
12. **SSE 和 WebSocket 有什么区别？** SSE 是服务器到客户端的单向事件流；WebSocket 是双向持久连接。
13. **前端为什么用 fetch 而不是 Axios 读取流？** 浏览器 fetch 暴露 `response.body` 的 `ReadableStream`，便于逐块读取。
14. **为什么 SSE 解析需要 buffer？** 网络分片可能在 UTF-8 字符或事件中途结束，不能假设一次读取就是一条事件。
15. **SQLite 的局限是什么？** 并发写入能力有限，不适合大量并发用户或多实例共享数据库。
16. **如何切换 PostgreSQL？** 替换 `DATABASE_URL`、安装驱动，并用 Alembic 管理数据库迁移。
17. **如果有 10 万份文档怎么办？** 引入后台任务、对象存储、批量索引、分页和更成熟的检索/权限架构。
18. **用户上传超大 PDF 怎么办？** 限制大小，流式写入，并把解析与向量化放到异步任务中。
19. **如何处理扫描版 PDF？** 加入 OCR；本项目当前只提取 PDF 内嵌文字。
20. **如何防止 prompt injection？** 把检索文本视为不可信数据，在系统提示中明确拒绝执行其中的指令；高风险场景还需过滤与隔离。
21. **如何减少 hallucination？** 限定仅根据检索资料回答，资料不足时明确说不知道，并展示引用供核查。
22. **如何优化检索质量？** 调整分块、embedding 模型和 top-k，加入混合检索、查询改写与 rerank。
23. **如何加入 rerank？** 先召回较多候选，再由重排模型评分，选最相关的少量 chunk 进入 Prompt。
24. **如何衡量 RAG 效果？** 建立问答样本集，评估检索命中率、答案正确性、引用准确性和延迟。
25. **为什么要存文档元数据？** 用于显示来源、按文档删除向量、统计和追踪引用。
26. **删除文档时为何还要删向量？** 否则检索可能继续命中已删除文档，形成脏数据。
27. **本项目的 SQLite 与 Chroma 各存什么？** SQLite 存文档清单、会话和消息；Chroma 存 chunk 正文、元数据与向量。
28. **为什么 API Key 放 `.env`？** 避免把密钥写入版本库，并便于不同环境配置。
29. **CORS 解决什么问题？** 控制哪些浏览器来源可以跨域调用后端 API。
30. **为什么需要统一异常处理？** 保证前端接收到稳定的错误结构，并让服务端日志保留排错信息。
31. **上传中途 Embedding 失败怎么办？** 回滚 SQL 事务，删除已写入的向量与上传文件。
32. **为什么不能只看模型回答里的引用？** 模型可能编造引用；要用检索结果的真实元数据核对。
33. **如何支持多用户？** 加认证、为文档和会话加入 owner_id，并在 SQL 与向量查询两侧强制过滤。
34. **如何避免 XSS？** 前端将 Markdown 生成的 HTML 经过 DOMPurify 清洗再显示。
35. **本项目最明显的性能瓶颈是什么？** 上传请求内同步解析和调用 Embeddings API；文档多时应移到后台任务。
